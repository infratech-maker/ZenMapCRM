# ターミナルプロンプトの操作方法

このドキュメントは、Cursorのターミナルで対話的なプロンプトを操作する方法を説明します。

## 現在の状況

ターミナルに以下のプロンプトが表示されています：

```
❯ No, abort
  Yes, I want to execute all statements
```

これは、DBスキーマのプッシュを実行するかどうかの確認プロンプトです。

## 操作手順

### 方法1: 矢印キーで選択（推奨）

1. **Cursorの下部にあるターミナルパネルをクリック**
   - ターミナルパネルが見えない場合は、`View` → `Terminal` で表示
   - または、ショートカットキー `Ctrl + `` (バッククォート) で表示/非表示

2. **ターミナルにフォーカスがあることを確認**
   - ターミナルパネル内をクリックして、カーソルが点滅していることを確認

3. **矢印キー（↓）を1回押す**
   - 「Yes, I want to execute all statements」が選択されます
   - 選択された行の前に `❯` が表示されます

4. **Enterキーを押す**
   - スキーマのプッシュが実行されます

### 方法2: キーボードで 'y' を入力

1. **ターミナルパネルをクリック**
2. **キーボードで `y` を入力**
3. **Enterキーを押す**

## ターミナルパネルの見つけ方

### Cursorの場合

1. **下部パネルを確認**
   - Cursorの画面下部に「TERMINAL」というタブがあるパネルを探す
   - 見つからない場合は、`View` → `Terminal` をクリック

2. **ショートカットキー**
   - `Ctrl + `` (バッククォート) でターミナルを表示/非表示
   - Macの場合は `Cmd + `` (バッククォート)

3. **ターミナルタブを確認**
   - 下部パネルに複数のタブがある場合、「TERMINAL」タブをクリック

## よくある問題

### Q: ターミナルパネルが見つかりません

A: 
- `View` → `Terminal` をクリック
- ショートカットキー `Ctrl + `` を押す
- 画面下部を確認（通常は画面の一番下に表示されます）

### Q: 矢印キーが効きません

A: 
- ターミナルにフォーカスがあることを確認（ターミナルパネル内をクリック）
- 方法2を使用：キーボードで `y` を入力してEnter

### Q: プロンプトが消えてしまいました

A: 
- ターミナルの履歴をスクロールして確認
- もう一度 `npm run db:push` を実行

### Q: カーソルが点滅していません

A: 
- ターミナルパネル内をクリックしてフォーカスを当てる
- マウスでターミナル内をクリック

## 実行後の確認

スキーマのプッシュが成功すると、以下のようなメッセージが表示されます：

```
✓ Pushing schema to database...
✓ Schema pushed successfully
```

エラーが表示された場合は、エラーメッセージを確認してください。

## 次のステップ

スキーマのプッシュが完了したら：

1. RailwayのPostgresサービスで「Database」タブを開く
2. テーブルが作成されていることを確認
3. Web AppとWorkerサービスの環境変数を設定
4. スタートコマンドを設定
5. デプロイを確認
