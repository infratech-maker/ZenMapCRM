# Cursorでターミナルを開く方法

このドキュメントは、Cursorでターミナルを開く方法を説明します。

## 方法1: ショートカットキー（最も簡単・推奨）

### Macの場合
```
Cmd + ` (バッククォート)
```
- `Cmd`キーとバッククォート（`）キーを同時に押す
- バッククォート（`）は、数字の1の左側、Tabキーの上にあるキー

### Windows/Linuxの場合
```
Ctrl + ` (バッククォート)
```
- `Ctrl`キーとバッククォート（`）キーを同時に押す

**このショートカットキーでターミナルが表示/非表示されます。**

---

## 方法2: コマンドパレットから開く

1. **コマンドパレットを開く**
   - Mac: `Cmd + Shift + P`
   - Windows/Linux: `Ctrl + Shift + P`

2. **'terminal' と入力**
   - 入力すると候補が表示されます

3. **'Terminal: Create New Terminal' を選択**
   - Enterキーを押すか、マウスでクリック

---

## 方法3: 画面下部のパネルを確認

1. **画面の一番下を見る**
   - Cursorの画面下部にパネルが表示されている場合があります

2. **'TERMINAL' というタブを探す**
   - 見つかったら、そのタブをクリック

3. **パネルが折りたたまれている場合**
   - パネルの上部をクリックして展開

---

## 方法4: メニューバーから開く（メニューバーが表示されている場合）

1. **画面上部のメニューバーを確認**
   - Macの場合、画面上部にメニューバーが表示されます

2. **'View' メニューをクリック**
   - メニューバーに「View」がある場合

3. **'Terminal' を選択**

**注意**: Cursorではメニューバーが非表示になっている場合があります。

---

## ターミナルが見つからない場合

### 確認事項

1. **ショートカットキーを試す**
   - `Cmd + ` (Mac) または `Ctrl + ` (Windows/Linux)
   - これが最も確実な方法です

2. **画面をリサイズする**
   - ターミナルパネルが画面外に隠れている可能性があります
   - ウィンドウサイズを調整してみてください

3. **Cursorを再起動**
   - まれに、ターミナルパネルが正しく表示されない場合があります
   - Cursorを再起動してみてください

---

## ターミナルが開いたら

1. **ターミナルパネル内をクリック**
   - フォーカスを当てます

2. **プロンプトを確認**
   - 以下のようなプロンプトが表示されているはずです：
     ```
     ❯ No, abort
       Yes, I want to execute all statements
     ```

3. **'y' を入力してEnter**
   - または、矢印キー（↓）で「Yes」を選択してEnter

---

## ショートカットキーの覚え方

- **バッククォート（`）の位置**:
  - Mac: 数字の1の左側、Tabキーの上
  - Windows: 数字の1の左側、Tabキーの上
  - キーボードの左上の方にあります

- **覚え方**: 
  - `Cmd/Ctrl + ` でターミナルをトグル（表示/非表示）
